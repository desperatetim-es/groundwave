# Style guide

## Product name

The product is written **groundwλve** (lowercase, with a Greek lambda, the symbol for wavelength) wherever people read it: the app, the window and tab titles, and documentation prose. The technical identifier stays plain ASCII **`groundwave`**: the repository, Go module, binary, folder and command names, and URLs. Give the lambda an accessible name for screen readers (the app's logo link is labeled "groundwave home").
